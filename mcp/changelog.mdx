## 2026-05-01

- Added native browser OAuth for remote MCP clients.
- Added OAuth protected-resource and authorization-server metadata endpoints.
- Added dynamic client registration for MCP clients.
- Added browser consent flow in the MCP console.
- Added structured MCP tool responses with `structuredContent`.
- Added product image URLs to search, product detail, and comparison responses.
- Added prepaid credit packs for MCP billing.

## Earlier

- Added hosted JSON-RPC MCP endpoint at `/api/v1/mcp/server`.
- Added `search_materials`, `get_product`, `find_alternatives`, and `compare_products`.
- Added internal RAG search and optional live search behavior.
