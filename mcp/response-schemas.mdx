---
title: "Response Schemas"
description: "JSON-RPC response examples for Peeko MCP tool calls."
---

Peeko MCP returns JSON-RPC responses. Tool calls include two parallel payloads:

- `content`: text blocks for MCP clients.
- `structuredContent`: structured JSON for clients that render products or inspect fields programmatically.

All examples below are synthetic and contain no real credentials.

## `search_materials`

Request:

```json
{
  "jsonrpc": "2.0",
  "id": 10,
  "method": "tools/call",
  "params": {
    "name": "search_materials",
    "arguments": {
      "query": "exterior porcelain tile dcof 0.42",
      "limit": 2
    }
  }
}
```

  "id": 10,

## `get_product`

Request:

```json
{
  "jsonrpc": "2.0",
  "id": 11,
  "method": "tools/call",
  "params": {
    "name": "get_product",
    "arguments": {
      "product_id": "00000000-0000-4000-8000-000000000001"
    }
  }
}
```

Response:

```json
{
  "jsonrpc": "2.0",
  "id": 11,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"id\": \"00000000-0000-4000-8000-000000000001\", \"title\": \"Exterior Grip Porcelain Tile\"}"
      }
    ],
    "structuredContent": {
      "id": "00000000-0000-4000-8000-000000000001",
      "title": "Exterior Grip Porcelain Tile",
      "url": "https://manufacturer.example/products/exterior-tile",
      "description": "Porcelain tile rated for exterior wet areas.",
      "manufacturer": "Example Tile Co.",
      "image_urls": ["https://manufacturer.example/images/exterior-tile.jpg"]
    }
  }
}
```

## `find_alternatives`

`find_alternatives` returns the same structured shape as `search_materials`.

```json
{
  "jsonrpc": "2.0",
  "id": 12,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"success\": true, \"query\": \"low-VOC resilient flooring\", \"results\": []}"
      }
    ],
    "structuredContent": {
      "success": true,
      "query": "low-VOC resilient flooring",
      "results": [],
      "search_filters": {},
      "filters": {},
      "summary": "Found 0 products",
      "metadata": {
        "results_count": 0
      },
      "error": null
    }
  }
}
```
