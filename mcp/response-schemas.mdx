---
title: "Response Schemas"
description: "JSON-RPC response examples for Peeko MCP tool calls."
---

Peeko MCP returns JSON-RPC responses. Tool calls include two parallel payloads:

- `content`: text blocks for MCP clients that only render text.
- `structuredContent`: structured JSON for clients that render products or inspect fields programmatically.

All examples below are synthetic and contain no real credentials or product data.

## `search_materials`

Request:

```json
{
  "jsonrpc": "2.0",
  "id": 10,
  "method": "tools/call",
  "params": {
    "name": "search_materials",
    "arguments": {
      "query": "exterior porcelain tile dcof 0.42",
      "limit": 2,
      "manufacturer": "Daltile",
      "min_score": 0.72
    }
  }
}
```

## `find_alternatives`

`find_alternatives` returns the same shape as `search_materials`, with `metadata.next_cursor` for pagination. The source product is excluded from results.

```json
{
  "jsonrpc": "2.0",
  "id": 12,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "{\"success\": true, \"query\": \"exterior porcelain tile dcof 0.42\", \"results\": [...]}"
      }
    ],
    "structuredContent": {
      "success": true,
      "query": "exterior porcelain tile dcof 0.42 — alternatives",
      "results": [],
      "search_filters": {},
      "filters": {},
      "summary": "Found 0 products",
      "metadata": {
        "results_count": 0,
        "next_cursor": null
      },
      "error": null
    }
  }
}
```
