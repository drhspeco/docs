## How it works

Peeko exposes a hosted MCP server at:

```text
https://api.getpeeko.ai/api/v1/mcp/server
```

MCP clients discover Peeko's OAuth metadata, open a browser consent page, and then call the server with an OAuth-issued bearer token. Developers do not need to create or paste API keys.

<Steps>
  <Step title="Add Peeko to Cursor">
    Configure Cursor with the hosted Peeko MCP server URL.
  </Step>
  <Step title="Approve access">
    Sign in to Peeko, review the MCP client request, and approve the `mcp` scope.
  </Step>
  <Step title="Run material searches">
    Ask your MCP client to search for construction products, alternatives, details, or comparisons.
  </Step>
  <Step title="Track usage">
    Successful tool calls consume credits from your MCP balance.
  </Step>
</Steps>
