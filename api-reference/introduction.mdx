The Getpeeko REST API gives you programmatic access to everything inside your workspace. You can create and manage projects, pull AI-generated insights into your own dashboards or data pipelines, and register webhook endpoints to react to events in real time. All communication uses standard HTTP methods and JSON, so you can integrate with any language or toolchain.

## Base URL

All API requests target the following base URL:

```bash
https://api.getpeeko.ai/v1
```

## Getting your API key

You need an API key to authenticate every request. Generate one in the Getpeeko app.

<Steps>
  <Step title="Log in to Getpeeko">
    Go to [app.getpeeko.ai](https://app.getpeeko.ai) and sign in to your account.
  </Step>
  <Step title="Open Settings">
    Click your workspace avatar in the bottom-left corner, then select **Settings**.
  </Step>
  <Step title="Navigate to API Keys">
    Select **API Keys** from the left-hand settings menu.
  </Step>
  <Step title="Create an API key">
    Click **Create API Key**.
  </Step>
  <Step title="Name your key">
    Enter a descriptive name — for example, `Production integration` or `CI pipeline` — so you can identify it later.
  </Step>
  <Step title="Copy and store it securely">
    Copy the key and save it somewhere safe, such as a secrets manager or environment variable. You will not be able to view it again after closing this dialog.
  </Step>
</Steps>

<Warning>
  Getpeeko displays your API key only once, immediately after creation. If you lose it, you must revoke the key and create a new one.
</Warning>

## Making requests

Pass your API key in the `Authorization` header of every request using the `Bearer` scheme.

<CodeGroup>

```bash curl
curl https://api.getpeeko.ai/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript javascript
const res = await fetch('https://api.getpeeko.ai/v1/projects', {
  headers: { 'Authorization': 'Bearer YOUR_API_KEY' }
});
const data = await res.json();
```

```python python
import requests

res = requests.get(
  'https://api.getpeeko.ai/v1/projects',
  headers={'Authorization': 'Bearer YOUR_API_KEY'}
)
print(res.json())
```

</CodeGroup>

## Response format

Every API response is JSON. Successful responses wrap the returned resource or list in a `data` field. Error responses include an `error` object with a machine-readable `code` and a human-readable `message`.

Example error response:

```json
{
  "error": {
    "code": "resource_not_found",
    "message": "No project with id proj_abc123 exists in this workspace."
  }
}
```

Common HTTP status codes:

| Status | Meaning |
|--------|---------|
| `200` | Request succeeded |
| `201` | Resource created |
| `204` | Request succeeded with no response body |
| `400` | Bad request — check your request body or query parameters |
| `401` | Unauthorized — missing or invalid API key |
| `403` | Forbidden — valid key but insufficient scope |
| `404` | Resource not found |
| `422` | Unprocessable entity — validation error |
| `429` | Too many requests — rate limit exceeded |
| `500` | Internal server error |

## API versioning

The current API version is `v1`, included in the URL path:

```bash
https://api.getpeeko.ai/v1/...
```

Getpeeko increments the version number (`v2`, `v3`, …) only when introducing breaking changes. Non-breaking additions — such as new optional fields or new endpoints — are added to the current version without a version bump. When a new major version is released, the previous version remains available for a deprecation period communicated in advance via email and in-app notifications.

<Note>
  The Getpeeko API enforces rate limits on all requests. See the [rate limits](/api-reference/rate-limits) page for per-plan quotas and guidance on handling `429` responses.
</Note>
