Projects are the top-level containers in Getpeeko. Each project connects to one or more data sources, runs AI-powered analyses, and accumulates insights over time. The projects API lets you manage the full lifecycle of a project — from creation to deletion — and integrate project metadata into your own tooling or dashboards.

---

## List projects

Retrieve all projects in your workspace.

```
GET /projects
```

### Query parameters

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Use with `per_page` to paginate through results.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  Number of projects to return per page. Maximum value is `100`.
</ParamField>

<ParamField query="status" type="string">
  Filter projects by status. Accepted values: `active`, `archived`. Omit this parameter to return projects of all statuses.
</ParamField>

### Response fields

<ResponseField name="data" type="array" required>
  Array of project objects.

  <Expandable title="project object fields">
    <ResponseField name="id" type="string" required>
      Unique identifier for the project, prefixed with `proj_`.
    </ResponseField>
    <ResponseField name="name" type="string" required>
      Display name of the project.
    </ResponseField>
    <ResponseField name="description" type="string">
      Optional description of the project's purpose or scope.
    </ResponseField>
    <ResponseField name="status" type="string" required>
      Current status of the project. One of `active` or `archived`.
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      ISO 8601 timestamp of when the project was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string" required>
      ISO 8601 timestamp of the most recent update.
    </ResponseField>
    <ResponseField name="run_count" type="integer" required>
      Total number of analysis runs completed for this project.
    </ResponseField>
    <ResponseField name="last_run_at" type="string">
      ISO 8601 timestamp of the most recent analysis run. `null` if no runs have been completed.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  Pagination metadata.

  <Expandable title="meta fields">
    <ResponseField name="total" type="integer" required>
      Total number of projects matching the query.
    </ResponseField>
    <ResponseField name="page" type="integer" required>
      Current page number.
    </ResponseField>
    <ResponseField name="per_page" type="integer" required>
      Number of results per page.
    </ResponseField>
  </Expandable>
</ResponseField>

## Create a project

Create a new project in your workspace.

```
POST /projects
```

### Body parameters

<ParamField body="name" type="string" required>
  Display name for the new project. Must be between 1 and 120 characters.
</ParamField>

<ParamField body="description" type="string">
  Optional description of the project. Maximum 500 characters.
</ParamField>

### Response

Returns the created project object.

<CodeGroup>

```bash curl
curl -X POST https://api.getpeeko.ai/v1/projects \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "New User Onboarding Funnel",
    "description": "Tracks drop-off and engagement patterns for users in their first 30 days."
  }'
```

```json response
{
  "data": {
    "id": "proj_ghi789",
    "name": "New User Onboarding Funnel",
    "description": "Tracks drop-off and engagement patterns for users in their first 30 days.",
    "status": "active",
    "created_at": "2026-05-01T08:00:00Z",
    "updated_at": "2026-05-01T08:00:00Z",
    "run_count": 0,
    "last_run_at": null
  }
}
```

</CodeGroup>

## Retrieve a project

Fetch a single project by its ID.

```
GET /projects/{id}
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the project (e.g., `proj_abc123`).
</ParamField>

### Response

Returns the project object. In addition to the standard fields, the response includes a `data_sources` array listing the data sources connected to the project.

<CodeGroup>

```bash curl
curl https://api.getpeeko.ai/v1/projects/proj_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json response
{
  "data": {
    "id": "proj_abc123",
    "name": "Mobile App Users Q1",
    "description": "Behavioral analysis of mobile users acquired in Q1 2026.",
    "status": "active",

    "updated_at": "2026-04-22T14:30:00Z",
    "run_count": 12,
    "last_run_at": "2026-04-22T14:30:00Z",
    "data_sources": [
      {
        "id": "ds_mno321",
        "name": "Segment — Mobile Events",
        "type": "segment",
        "connected_at": "2026-01-10T09:20:00Z"
      }
    ]
  }
}
```

</CodeGroup>

## Delete a project

Permanently delete a project and all of its associated data.

```
DELETE /projects/{id}
```

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the project to delete (e.g., `proj_abc123`).
</ParamField>

<Warning>
  Deleting a project is permanent and cannot be undone. All insights, analysis runs, and connected data source configurations associated with the project are removed immediately. Archive the project instead if you might need to access its data in the future.
</Warning>

### Response

Returns `204 No Content` on success. No response body is included.

<CodeGroup>

```bash curl
curl -X DELETE https://api.getpeeko.ai/v1/projects/proj_abc123 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

</CodeGroup>
