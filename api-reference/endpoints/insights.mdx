Insights are the AI-generated findings that Getpeeko surfaces from your project's data. Each insight includes a natural-language finding, a confidence score, supporting metrics, and tags that classify the type of pattern detected. Use the insights API to pull findings into your own dashboards, trigger downstream workflows, or build custom reporting on top of Getpeeko's analysis engine.

---

## List insights for a project

Retrieve a paginated list of insights generated for a specific project.

```
GET /projects/{project_id}/insights
```

### Path parameters

<ParamField path="project_id" type="string" required>
  The unique identifier of the project (e.g., `proj_abc123`).
</ParamField>

### Query parameters

<ParamField query="page" type="integer" default="1">
  Page number to retrieve.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  Number of insights to return per page. Maximum value is `100`.
</ParamField>

<ParamField query="min_confidence" type="float">
  Return only insights with a confidence score greater than or equal to this value. Accepts a decimal between `0` and `1`. For example, `0.75` returns insights with at least 75% confidence.
</ParamField>

<ParamField query="tags" type="string">
  Comma-separated list of tags to filter by. Returns insights that match at least one of the provided tags. For example, `retention,churn`.
</ParamField>

<ParamField query="from" type="string">
  ISO 8601 date string. Return only insights created on or after this date. For example, `2026-01-01`.
</ParamField>

<ParamField query="to" type="string">
  ISO 8601 date string. Return only insights created on or before this date. For example, `2026-04-30`.
</ParamField>

<ParamField query="sort" type="string" default="confidence_desc">
  Sort order for results. Accepted values: `confidence_desc` (highest confidence first), `created_at_desc` (most recent first).
</ParamField>

### Response fields

<ResponseField name="data" type="array" required>
  Array of insight objects.

  <Expandable title="insight object fields">
    <ResponseField name="id" type="string" required>
      Unique identifier for the insight, prefixed with `ins_`.
    </ResponseField>
    <ResponseField name="title" type="string" required>
      Short, human-readable title summarising the insight.
    </ResponseField>
    <ResponseField name="finding" type="string" required>
      Full natural-language description of what the AI found. This is the primary output of the analysis.
    </ResponseField>
    <ResponseField name="confidence" type="float" required>
      AI confidence score for this insight, expressed as a decimal between `0` and `1`. Higher values indicate stronger statistical support.
    </ResponseField>
    <ResponseField name="tags" type="string[]" required>
      Array of classification tags (e.g., `["retention", "mobile"]`).
    </ResponseField>
    <ResponseField name="supporting_data" type="object" required>
      Quantitative data that supports the finding.

      <Expandable title="supporting_data fields">
        <ResponseField name="metric_name" type="string">
          The name of the primary metric underlying the insight (e.g., `7-day retention rate`).
        </ResponseField>
        <ResponseField name="value" type="number">
          The current measured value of the metric.
        </ResponseField>
        <ResponseField name="comparison_value" type="number">
          The baseline or prior period value used for comparison.
        </ResponseField>
        <ResponseField name="change_pct" type="number">
          Percentage change from `comparison_value` to `value`. Negative values indicate a decline.
        </ResponseField>
        <ResponseField name="chart_type" type="string">
          Suggested chart type for visualising this insight. For example, `line`, `bar`, or `funnel`.
        </ResponseField>
      </Expandable>
    </ResponseField>
    <ResponseField name="created_at" type="string" required>
      ISO 8601 timestamp of when this insight was generated.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object" required>
  Pagination metadata.

  <Expandable title="meta fields">
    <ResponseField name="total" type="integer" required>
      Total number of insights matching the query.
    </ResponseField>
    <ResponseField name="page" type="integer" required>
      Current page number.
    </ResponseField>
    <ResponseField name="per_page" type="integer" required>
      Number of results per page.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>

curl "https://api.getpeeko.ai/v1/projects/proj_abc123/insights?min_confidence=0.75&sort=confidence_desc&per_page=2" \

## Retrieve a single insight

Fetch the full details of one insight by its ID.

```
GET /projects/{project_id}/insights/{id}
```

### Path parameters

<ParamField path="project_id" type="string" required>
  The unique identifier of the project.
</ParamField>

<ParamField path="id" type="string" required>
  The unique identifier of the insight (e.g., `ins_xyz789`).
</ParamField>

### Response

Returns the full insight object, identical in structure to the objects returned by the list endpoint.

<CodeGroup>

```bash curl
curl https://api.getpeeko.ai/v1/projects/proj_abc123/insights/ins_xyz789 \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json response
{
  "data": {
    "id": "ins_xyz789",
    "title": "Day-7 retention drops sharply for users who skip onboarding",
    "finding": "Users who bypass the onboarding checklist have a 7-day retention rate of 28%, compared to 61% for users who complete it. This 33-percentage-point gap is the strongest predictor of early churn in this cohort.",
    "confidence": 0.94,
    "tags": ["retention", "onboarding", "mobile"],
    "supporting_data": {
      "metric_name": "7-day retention rate",
      "value": 0.28,
      "comparison_value": 0.61,
      "change_pct": -54.1,
      "chart_type": "bar"
    },
    "created_at": "2026-04-22T14:30:00Z"
  }
}
```

</CodeGroup>

<Tip>
  Use `min_confidence=0.8` when filtering the list endpoint to surface only high-confidence findings. Insights above this threshold have strong statistical backing and are the most actionable starting point for product or marketing decisions.
</Tip>
